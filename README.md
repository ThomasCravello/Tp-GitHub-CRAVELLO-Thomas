# Tp-GitHub Locky
  Locky est un rançongiciel (ransomware) malveillant découvert en février 2016 qui chiffre les fichiers d'un ordinateur et réclame une rançon en bitcoins. [1] (https://fr.wikipedia.org/wiki/Locky), [2] (https://korben.info/locky-quil-y-a-a-savoir-malware-moment.html), [3] (https://www.pandasecurity.com/fr/mediacenter/quest-ce-quun-virus-locky/)Fonctionnement de l'attaquePropagation : Le virus arrive par e-mail sous forme de fausse facture (souvent au format Word ou ZIP). [1] (https://www.interieur.gouv.fr/archive/un-nouveau-rancongiciel-nomme-locky-arrive-en-france), [2] (https://fr.wikipedia.org/wiki/Locky)infection : Le document demande d'activer les macros Microsoft Word. [1] (https://fr.wikipedia.org/wiki/Locky)Chiffrement : Une fois activées, les macros lancent un code qui télécharge le malware et crypte les documents, photos et vidéos de la victime. [1] (https://www.mimecast.com/fr/content/locky-ransomware/), [2] (https://fr.wikipedia.org/wiki/Locky)Rançon : Le fond d'écran change et une note exige un paiement en bitcoins via le réseau Tor pour obtenir un moyen de déchiffrement incertain. [1] (https://korben.info/locky-quil-y-a-a-savoir-malware-moment.html), [2] (https://www.youtube.com/watch?v=9mkptCXjMbw&t=248), [3] (https://fr.wikipedia.org/wiki/Locky)Comment se protégerPrudence : Ne jamais ouvrir les pièces jointes d'e-mails suspects.Macros : Désactiver l'activation automatique des macros dans les logiciels bureautiques.Sauvegardes : Conserver des sauvegardes régulières des données sur des supports déconnectés.Assistance : En cas d'incident, consulter la plateforme officielle Cybermalveillance.gouv.fr pour obtenir de l'aide. [1] (https://www.cybermalveillance.gouv.fr/tous-nos-contenus/actualites/outil-de-dechiffrement-du-rancongiciel-ransomware-pylocky-versions-1-et-2), [2] (https://www.groupeadinfo.com/actu/alerte-virus-locky/)
